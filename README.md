# HBE_2206 | Python for AI

A structured, practical Python learning series preparing for AI and Machine Learning.

## Learning Series
- **Part 1 — Core Python Foundations:** syntax, variables, data types, operators, strings, data structures, conditions, loops, and beginner problem solving.
- **Part 2 — Professional Python:** functions, Pythonic code, exceptions, file handling, JSON, OOP, modules/packages, testing, environments, and AI-oriented coding practices.

## Recommended workflow
1. Review the study slides.
2. Run the notebook or Python examples.
3. Attempt the exercises independently.
4. Compare with reference solutions only after trying.
5. Keep notes on errors, outputs, and concepts that need revision.

## Requirements
- Python 3.10 or later recommended.
- Jupyter Notebook or Google Colab for notebooks.
- Core examples use the Python standard library.
