# Learning Path — Python for AI

This guide describes a recommended route through the materials in this repository.

## Stage 1 — Core Python

**Goal:** become comfortable reading and writing small Python programs.

Study variables, types, operators, strings, collections, conditions, loops, and basic problem solving.

Materials:
- [Part 1 study notes](../code/Python_Part1_Study_Notes.ipynb)
- [Part 1 practice notebook](../code/Python_Part1_Practice.ipynb)
- [Runnable examples](../code/python_part1_examples.py)

**Ready to continue when:** you can write a small program using conditions, loops, and lists without copying a full example.

## Stage 2 — Professional Python

**Goal:** organize programs and work with structured data/files.

Study functions, arguments, scope, comprehensions, exceptions, file handling, JSON, OOP, modules, environments, and basic testing.

Materials:
- [Part 2 study notes](../code/Python_Part2_Study_Notes.ipynb)
- [Part 2 guide](../part-2/README.md)
- [Part 2 exercises](../exercises/part2_exercises.md)
- [Reference solutions](../part-2/solutions.py)

**Applied task:** complete the Student Record Manager mini-project and explain how its functions and data structures work.

## Stage 3 — NumPy

**Goal:** perform numerical work efficiently with arrays.

Study array creation, shape and dimensions, indexing/slicing, vectorized operations, broadcasting, aggregations, boolean masks, and reproducible random values.

Material: [NumPy study notebook](../libraries/numpy/NumPy_for_AI_Study_Notes.ipynb)

**Applied task:** calculate descriptive statistics and filter values in a small numerical dataset.

## Stage 4 — Pandas

**Goal:** inspect and prepare tabular data.

Study Series/DataFrames, reading data, selecting/filtering rows and columns, sorting, missing values, duplicates, data types, grouping, aggregation, and merging.

Material: [Pandas study notebook](../libraries/pandas/Pandas_for_AI_Study_Notes.ipynb)

**Applied task:** clean a small dataset and report key group-level summaries. Explain decisions made for missing data rather than filling values blindly.

## Stage 5 — Matplotlib

**Goal:** select and create charts that answer a data question.

Study line, bar, scatter, histogram, labels, legends, multiple series, subplots, saving figures, and plots from Pandas data.

Material: [Matplotlib study notebook](../libraries/matplotlib/Matplotlib_for_AI_Study_Notes.ipynb)

**Applied task:** produce at least three complementary charts for a dataset and write one or two evidence-based observations for each chart.

## Stage 6 — Machine Learning foundations

Move on after you can load, clean, summarize, and visualize data. The next stage should introduce problem framing, feature/target separation, train/test splits, baseline models, evaluation metrics, and leakage prevention.

## Recommended study loop

1. Read the explanation.
2. Predict the code's output.
3. Run the code and explain the result in your own words.
4. Change one input and predict what will happen.
5. Complete exercises without viewing the solution.
6. Finish the applied task and record what you learned.
