# HBE_2206 | Python Part 1 — Exercises

Try each exercise before opening `solutions.py`. Use only Python's built-in features.

## Easy
1. Create variables for a model name, number of samples, and accuracy. Print their types.
2. Ask the user for an integer and print its square. Handle the fact that `input()` returns a string.
3. Given `text = "  Machine Learning  "`, remove surrounding whitespace and print the lowercase version.
4. Given a list of scores, append a new score, update one existing value, and print the final list.
5. Create a dictionary with `accuracy` and `recall`. Print `precision` with a default value of `0.0` if it is missing.

## Medium
6. Ask for a number and print whether it is positive, negative, or zero.
7. Print integers from -5 through 5 inclusive.
8. Given a list of confidence scores, create a new list containing only values >= 0.80.
9. Count the number of occurrences of each label in `labels = ["cat", "dog", "cat", "bird", "dog", "cat"]`.
10. Given a list of numbers, build a dictionary mapping each number to its square.

## Challenge
11. Given a list of scores, print count, minimum, maximum, and average without importing external libraries.
12. Given a list of strings, keep only non-empty strings after stripping whitespace.
13. Given two lists `keys` and `values` of equal length, combine them into a dictionary.
14. Write a small menu loop that exits when the user enters `q`.
15. Explain in comments when a list, tuple, set, or dictionary is the best choice.
