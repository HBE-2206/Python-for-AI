### Why this order?

- **NumPy** gives us the numerical array foundation.
- **Pandas** helps organize and analyze real-world tables, including missing values.
- **Matplotlib** turns values and summaries into interpretable visualizations.

These tools complement one another and are commonly used together in data analysis workflows.

## How each lesson should work

Each topic should help a learner move through this loop:

1. **Goal:** what you will learn and why it matters.
2. **Concept:** explanation in plain language, with terminology defined.
3. **Code:** a focused example that can be run independently.
4. **Expected result:** output or plot, plus an explanation of what it means.
5. **Practice:** exercises that progress from basic to applied.
6. **Application:** a realistic mini-task using the concept.
7. **Recap:** key takeaways and a self-check.

## Current topic — Matplotlib

Matplotlib is a Python plotting library used to create charts and customize figures. It helps communicate the shape, distribution, relationship, and comparison of data. It does **not** automatically determine whether a chart is statistically appropriate; the learner must choose a visualization that fits the question and data.

### Topics checklist

- [ ] Installation and importing `matplotlib.pyplot`

- [ ] Line charts for trends
