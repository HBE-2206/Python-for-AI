## Recommended study workflow

1. Read one section and note the key idea.
2. Predict what the code will do before running it.
3. Run the code and compare the result with your prediction.
4. Complete the related practice task without copying the example.
5. Review the solutions only after making a genuine attempt.

## Topics

Variables and types, operators, strings, collections, input/output, conditions, loops, comprehensions, and foundational problem-solving.

## Setup

Install Python 3 and use a notebook environment such as Jupyter. To install Jupyter:

```bash
python -m pip install jupyter
```

From the repository root, launch it with:

```bash
jupyter notebook
```
