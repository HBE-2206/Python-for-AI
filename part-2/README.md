# Python Part 2 — Professional Python

**Author:** Hazem Elshafey  
**Series:** Python for AI | Learning Journey

Part 2 builds on Core Foundations and focuses on writing reusable, maintainable Python programs.

## Learning outcomes
- Write functions with parameters, default values, return values, and docstrings.
- Use comprehensions and built-in functions appropriately.
- Understand syntax errors, runtime exceptions, and logic errors.
- Handle expected exceptions and validate user input.
- Read and write text files and JSON.
- Create classes and objects; understand inheritance and polymorphism.
- Organize code with modules and packages.
- Use a virtual environment and install dependencies with pip.
- Test code and debug problems systematically.

## How to study
1. Read the concept in the notebook.
2. Predict the code output before running the cell.
3. Run the notebook from top to bottom.
4. Complete the exercises without looking at solutions.
5. Run the reference checks with `python part-2/solutions.py`.

## Run the examples
From the repository root:

```bash
python code/python_part2_examples.py
```

## Mini-project: Student Record Manager
Build a command-line program that adds student records, validates scores from 0 to 100, calculates averages, saves and loads records in JSON, and handles missing or malformed files. Split the solution into focused functions and test normal, boundary, and invalid cases.

## Important notes
- The environment activation command depends on the operating system and shell.
- `assert` is useful for simple checks but can be disabled with Python optimization; do not use it for essential runtime validation.
- These are educational examples. Review and test code before reusing it in a production project.
