# HBE_2206 | AI Engineering Training Hub

**Author:** Hazem Elshafey  
**Purpose:** Reusable training materials and a practical AI engineering portfolio.

## Mission

This repository area organizes training content into teachable modules that include explanations, notebooks, exercises, projects, assessments, and reproducible setup instructions.

## Learning path

1. **Prerequisites & Python for AI** — Python, NumPy, Pandas, [Data Visualization with Matplotlib & Seaborn](python-for-ai/visualization/README.md), then Math & Statistics for ML.
2. **Machine Learning** — problem framing, data preparation, supervised learning, unsupervised learning, evaluation, pipelines, and model interpretation.
3. **Deep Learning** — neural network fundamentals, training loops, regularization, CNNs, sequence models, and practical evaluation.
4. **Specialization paths** — Computer Vision, NLP, and LLMs, developed after the foundations.

The sequence and depth will be finalized after reviewing the existing source materials.

## Repository structure

- `ml/` — Machine Learning modules.
- `deep-learning/` — Deep Learning modules.
- `templates/module-template/` — reusable module structure and checklist.
- `assets/` — shared diagrams and visual assets where licensing permits.

## Module standard

Each module should include:
- Learning objectives and prerequisites
- Concept notes or slides
- A detailed Jupyter notebook with code and expected outputs
- Exercises and assessment criteria
- A practical project with reproducible instructions
- References, dataset provenance, and license notes
- Environment/setup instructions and a completion checklist

## Quality gates

Before a module is marked complete:
1. Run notebooks from top to bottom in a clean environment.
2. Verify outputs, imports, dataset paths, and random seeds where relevant.
3. Check that explanations match the code and avoid unsupported claims.
4. Include dataset sources and usage licenses.
5. Make exercises and assessment criteria understandable to learners.
6. Update the module README with run instructions and known limitations.
