# Project — Deep Learning Foundations

## Objective
Fashion-MNIST classifier: train a PyTorch MLP, compare with a baseline and document curves and errors.

## Workflow
1. Define problem and success criteria.
2. Record dataset/source, license and permitted use.
3. Inspect data and define evaluation protocol.
4. Build a baseline.
5. Implement method and record parameters.
6. Evaluate and inspect errors.
7. Explain limitations.

## Deliverables
- Reproducible notebook
- README with setup, method, results and limitations
- Result table or visualization
