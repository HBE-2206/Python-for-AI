# ML-00 — Machine Learning Fundamentals & Workflow

**Track:** Machine Learning  
**Author:** Hazem Elshafey | HBE_2206  
**Status:** Initial draft

## Purpose

Introduce a reliable end-to-end supervised-learning workflow before learners study individual algorithms in depth.

## Learning objectives

Learners should be able to:
- Distinguish supervised learning, unsupervised learning, regression, and classification at a high level.
- Identify features, target, rows, and columns in a tabular dataset.
- Create a train/test split and explain why test data should not guide model selection.
- Fit a simple baseline model and calculate an appropriate metric.
- Recognize data leakage and explain why a baseline matters.

## Planned contents

- `notebooks/ML_00_Fundamentals_and_Workflow.ipynb` — guided notebook.
- `exercises/README.md` — practice questions and tasks.
- `project/README.md` — small applied challenge.

## Initial practical example

Use a small, synthetic tabular dataset to demonstrate the workflow without relying on a downloaded dataset. A real dataset and larger project can be selected after the existing materials are reviewed.

## Setup

Recommended:
- Python 3.10+
- Jupyter Notebook or Google Colab
- NumPy, Pandas, Matplotlib, scikit-learn

Install the dependencies in a virtual environment or notebook environment before running the notebook.

## Assessment

Learners should submit:
1. A completed notebook.
2. Answers explaining features, target, split, baseline, and metric.
3. A short note describing one possible source of data leakage.
