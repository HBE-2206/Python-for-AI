# Mini-Project — Predict a Numeric Outcome

**Module:** ML-00 — Machine Learning Fundamentals & Workflow  
**Level:** Beginner  
**Dataset:** Synthetic data generated inside the notebook; no external download required.

## Problem

Build a small, reproducible regression workflow that predicts a numeric target from two or more input features.

## Requirements

1. Inspect the dataset and identify the features and target.
2. Split the data into training and test sets.
3. Fit a simple baseline model.
4. Fit a linear regression model.
5. Evaluate both models with MAE and RMSE.
6. Compare results and explain the limitations of synthetic data.
7. Document the random seed and steps needed to reproduce the experiment.

## Deliverables

- A completed Jupyter notebook.
- A short README with the approach and results.
- A brief explanation of baseline vs. trained-model performance.
- One limitation and one proposed next step.

## Evaluation rubric

| Criterion | Weight |
|---|---:|
| Correct problem setup and feature/target separation | 20% |
| Correct split and leakage awareness | 20% |
| Reproducible implementation | 20% |
| Appropriate metrics and interpretation | 25% |
| Clear documentation and limitations | 15% |

## Important

Do not claim that results on synthetic data demonstrate real-world performance. The goal is to learn the workflow. A real-world dataset can be introduced in a later project.
