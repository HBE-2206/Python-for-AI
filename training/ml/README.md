# Machine Learning Track

**Series:** HBE_2206 | AI Engineering Training Hub  
**Author:** Hazem Elshafey

## Track objective

Teach learners to formulate ML problems, prepare data, train and evaluate models, and communicate results using reproducible Python workflows.

## Proposed module sequence

1. **ML-00 — Machine Learning Fundamentals & Workflow**  
   Problem types, features and targets, train/test split, baseline models, leakage awareness, and evaluation workflow.
2. **ML-01 — Data Preparation & Feature Engineering**  
   Missing values, categorical variables, scaling, preprocessing, and pipelines.
3. **ML-02 — Regression**  
   Linear regression, regularization concepts, regression metrics, residual analysis.
4. **ML-03 — Classification**  
   Logistic regression, k-nearest neighbors, decision trees, and classification metrics.
5. **ML-04 — Model Evaluation & Validation**  
   Cross-validation, class imbalance, threshold selection, confusion matrix, ROC-AUC where appropriate.
6. **ML-05 — Tree Ensembles & Model Interpretation**  
   Random forests, gradient boosting concepts, feature importance, limitations.
7. **ML-06 — Unsupervised Learning**  
   Clustering, dimensionality reduction concepts, and appropriate evaluation caveats.
8. **ML-07 — End-to-End ML Project**  
   Reproducible preprocessing and modeling, error analysis, documentation, and optional lightweight deployment.

## First module

Start with [ML-00 — Fundamentals & Workflow](ML-00-fundamentals/README.md).

## Curriculum note

This is a proposed sequence, not a claim that every topic is already covered. It will be updated after the existing materials are reviewed. Module depth, library choices, and assessments should match the learners' prerequisites and training duration.
