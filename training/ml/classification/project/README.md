# Project — Classification Algorithms

## Objective
Customer Churn Classification: compare baseline and classifiers; explain recall/precision trade-offs and threshold selection.

## Workflow
1. Define the problem and success criteria.
2. Record dataset/source, license and permitted use.
3. Inspect and prepare data; define an evaluation protocol.
4. Build a simple baseline.
5. Implement the method and record parameters.
6. Evaluate with suitable metrics and inspect errors.
7. Explain limitations and next steps.

## Deliverables
- Reproducible notebook.
- README with problem, data provenance, setup, method, results and limitations.
- Result table or visualization.
