# HBE_2206 | Data Visualization with Matplotlib & Seaborn

**Author:** Hazem Elshafey  
**Track:** Python for AI  
**Status:** Draft — validate the notebook before marking this module complete.

## Purpose
Learn to explore and communicate data visually before moving into Machine Learning. This module follows Pandas in the learning sequence.

## Learning objectives
By the end, learners should be able to:
- Select a chart type for a specific analytical question.
- Create and customize charts with Matplotlib.
- Use Seaborn for statistical visualization.
- Interpret distributions, category comparisons, relationships, and correlations.
- Explain chart limitations and avoid misleading visual design.

## Prerequisites
- Basic Python
- Pandas DataFrames and basic filtering/grouping
- Basic NumPy arrays

## Module outline
1. Chart purpose and choosing a visualization
2. Matplotlib figure/axes, titles, labels, legends, and layout
3. Histograms and distributions
4. Scatter plots and relationships
5. Bar charts and category comparisons
6. Box plots and spread
7. Correlation heatmaps
8. Interpretation, chart quality, and responsible visualization

## Suggested delivery
Flexible: one 2-hour session for guided concepts and notebook work, plus 1–2 hours for exercises/project. Adjust to learner readiness.

## Run locally
1. Create/activate a Python environment.
2. Install dependencies: `pip install numpy pandas matplotlib seaborn jupyter`
3. Launch Jupyter: `jupyter notebook`
4. Open the notebook and run all cells from top to bottom.

## Completion criteria
- Notebook runs from top to bottom in a clean environment.
- Learner creates at least four chart types.
- Every chart has a clear title and labeled axes.
- Learner writes at least three observations supported by the plots.
- Learner notes at least one limitation and avoids causal claims from correlation.

## Known limitations
The starter notebook uses synthetic data to avoid external dataset downloads. The notebook has not yet been executed in a clean environment; verify imports and outputs before release. Add a real dataset and its provenance/license if the module is later expanded.
