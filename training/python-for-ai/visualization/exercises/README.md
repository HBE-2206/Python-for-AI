# Data Visualization — Exercises

**Brand:** HBE_2206 | **Author:** Hazem Elshafey

Use the notebook dataset unless an exercise asks you to create a new one. Submit code, charts, and a short interpretation for each task.

## Level 1 — Foundations
1. Create a histogram of `attendance`; choose a reasonable bin count and explain the choice.
2. Create a bar chart of the mean `score` for each `group`.
3. Add a descriptive title, axis labels, and a legend where needed.

## Level 2 — Relationships
4. Plot `study_hours` against `score` and color points by `group`.
5. Create box plots of `score` by `group`. Compare median and spread.
6. Create a correlation heatmap for the numeric columns and explain why correlation is not proof of causation.

## Level 3 — Communicate findings
7. Create two different chart types for the same question. Explain which is clearer and why.
8. Write three observations supported by the charts and one limitation of the dataset.
9. Improve a deliberately cluttered chart: remove unnecessary decoration, improve labels, and ensure the scale is not misleading.

## Deliverables
- Notebook with all exercises completed.
- At least four readable charts.
- Short interpretation (150–250 words).
- One limitation or uncertainty statement.

## Suggested rubric (100 points)
- Correct chart choice and code: 30
- Labels, readability, and layout: 20
- Interpretation grounded in evidence: 25
- Limitations and responsible presentation: 15
- Reproducibility and organization: 10
