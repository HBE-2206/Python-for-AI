# Mini-Project: Student Performance Visual Report

**Brand:** HBE_2206 | **Author:** Hazem Elshafey

## Scenario
Prepare a concise visual report exploring patterns in a student-performance dataset. Start with the synthetic dataset in the module notebook. Using a real dataset is optional; if you do, cite its source and license.

## Questions to investigate
1. How are scores distributed?
2. How do mean and median scores compare across groups?
3. Is study time associated with scores in this sample?
4. How does attendance relate to scores?
5. What can the charts not tell us?

## Required visuals
- Histogram of scores
- Bar chart comparing a group-level summary
- Scatter plot of study hours vs. score
- Box plot comparing score spread by group
- Correlation heatmap of numeric variables

## Deliverables
1. A clean Jupyter notebook that runs from top to bottom.
2. A short report (3–5 evidence-based findings).
3. A limitations section, including the synthetic nature of the starter data.
4. A README with run instructions and dependencies.

## Acceptance criteria
- Every chart has a useful title and labeled axes.
- Chart types match the questions being asked.
- Findings are supported by displayed data rather than assumptions.
- No causal claim is made from correlation alone.
- The notebook runs in a fresh environment.

## Optional extension
Use a public dataset, document its provenance and license, and recreate the report. Do not upload sensitive personal data.
